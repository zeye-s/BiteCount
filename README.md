# BiteCount
BiteCount is a nutrition tracker that keeps track of your diet. 
The app is built for Android and is built on TypeScript, React Native & Expo, and Open Food Facts API and is very simple to use.

Features:
  Toggle between a dark and a light green color scheme
  Edit your goal intake by clicking the individual card elements
  Share your progress by copying using a button
  Displays your five most recent meals 
  Stores meals using asyncStorage and a delete button that deletes all stored meal
  A search bar (barcodes only) that displays the nutrient of a product in a list
  A camera feature that scans the barcode
  An input option that changes the size of the meal(like 100g, 50g, etc.)
  Clicking the list automatically enters the information 
      information will not reset until you submit so you can scan other products and add that to the same form
  Submitting the form saves the meal information and date it is created at and updates the homescreen

Make every Bite Count!
