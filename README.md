# BiteCount
a nutrtition tracker built on React Native, Expo, and Open Food Facts API.
Input the barcode of a food product to obtain its nutrition values. Add the meals using these values which is then handled using async storage. Currently only displays the daily intake for the macro nutrients and calories (gonna fix that later). If inputted nothing, the search bar defaults to Nutella. 

#This is intended to be ran in the Expo app. To launch the app, open a terminal while inside the actual app folder (the BiteCount Folder inside the repo) and type npx expo start or npm start. It then launches a QR code which can be scanned to access the app inside Expo or click the local host option for the web version. If the web version displays an error, go to sitemap and click on the files under the Tabs folder.
